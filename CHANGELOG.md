# Changelog

All notable changes to this project will be documented in this file.

## [0.2.0] - 2026-05-05

### Added

- GD library fallback when ImageMagick is unavailable

## [0.1.0] - 2026-05-05

### Added

- Initial release
- Automatic AVIF conversion on image upload
- Manual conversion button in media library
- Support for JPEG, PNG, WebP, and GIF source formats
- Automatic URL rewriting for converted images
- Srcset filter support for responsive images
